# 🎥 PeerCast

## 🚀 Mission
PeerCast's mission is to make **seamless, local-first video streaming** between devices simple, fast, and private.  
No cloud uploads. No third-party servers. Just your devices, your network, and smooth streaming.  

Our goal is to build a **lightweight, cross-platform solution** that allows:
- **Laptop → Phone streaming** for quick watching on mobile.
- **Phone → Laptop streaming** for easy sharing without USB or cloud.
- **Privacy-first architecture** with local network streaming and optional peer-to-peer (P2P) connections.
- **Future expandability** for music, photos, and real-time screen casting.
